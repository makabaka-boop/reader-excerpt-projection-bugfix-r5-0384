# 书稿阅读器（React + TypeScript）

导入由「章节 + 段落」组成的本地 JSON 书稿，在规范化文字上做跨文本节点选区批注。
批注锚点是唯一状态源：持久化、画面高亮、导出都取自同一份锚点状态。

## 运行

```bash
npm install
npm run dev       # 开发
npm test          # 52 个单测/集成测试（vitest + jsdom）
npm run build     # 类型检查 + 生产构建
```

## 书稿 JSON 格式

```json
{
  "id": "book-1",
  "title": "书名",
  "version": "1",
  "chapters": [
    {
      "id": "ch1",
      "title": "第一章",
      "paragraphs": ["段落一", { "id": "p2", "text": "段落二" }]
    }
  ]
}
```

内置「示例 v1 / 示例 v2」两个按钮，v2 相对 v1 覆盖：段落拆分、跨节点选区、
重复短句（多处匹配）、文字插入、文字删除（失联）。

## 锚点模型（`src/types.ts`）

每条批注保存一个 `Anchor`：

- `chapterId`：章节身份（不依赖章节序号）
- `start` / `end`：章节扁平文字中的规范化偏移（快速路径）
- `text`：选中文字（跨段时保留 `\n` 段界定符）
- `prefix` / `suffix`：两侧各 32 字上下文（重锚证据）

### 规范化（`src/text/normalize.ts`）

逐段 NFKC + 空白折叠（换行/制表/连续空格归一）。关键点：全角中文标点
（`，。：；！？…` 等）经 NFKC 会被错误映射成 ASCII 标点，因此仅对
「NFKC 结果为纯 ASCII 且不含受保护全角标点」的字素簇应用 NFKC
（兼容连字 `ﬁ`、全角字母/数字等），中文标点原样保留。同时建立正/逆映射，
DOM 原始偏移与规范化偏移可双向换算。

### 扁平文字（`src/text/flatten.ts`）

每章把规范化段落以 `\n` 连接，记录每段 `start/textEnd/end`。选区坐标
全部基于文字偏移，与字号、窗口宽度、换行位置无关——所以改字号/拖窗口后
只需按 Range 重新测量高亮矩形，锚点永不漂移。

## 重锚（`src/text/anchor.ts`）

导入同书新版本（同 `id`、不同 `version`）时，对每条批注：

1. 在章节「去段界」连续文字中查找选中文字；
2. **0 次匹配** → `lost`：保留原锚点与上下文作为证据，不放置任何高亮，绝不猜测；
3. **1 次匹配** → `anchored`：自动迁移（段落拆分天然支持，段界被忽略）；
4. **多次匹配** → `ambiguous`：全部候选按两侧上下文吻合度评分降序，侧栏
   逐条展示「前文【命中】后文」证据，由人工裁决；也可显式标记失联。

同版本重载（刷新页面）走 `ensureAnchored`：坐标与文字均吻合的批注原样保留，
避免把本来唯一的批注误翻成「待裁决」。

## 界面行为

- 拖选（可跨段）后弹出批注框；`Ctrl/⌘+Enter` 保存
- 高亮是覆盖在文字上的矩形层（`Range.getClientRects`），字号/栏宽变化、
  窗口 resize 后自动重算
- 重叠批注：点击命中处循环选中各条，可分别编辑备注、删除
- 侧栏分组：待裁决 / 失联 / 已定位；失联批注展示原文与两侧上下文证据
- 导出 JSON（含全部状态与锚点证据），localStorage 按书 id 持久化

## 测试覆盖（`src/**/*.test.ts`）

- 规范化：空白折叠、受控 NFKC、全角标点保护、映射单调性
- 扁平化：段界偏移、DOM ↔ 规范化偏移往返
- 重锚：段落拆分、跨节点选择、重复短句（待裁决+评分排序）、文字插入后
  坐标漂移纠正、找不到（失联保证据）、章节删除、人工裁决、批量独立判定
- jsdom 选区：真实 Selection/Range 跨段读取、反向端点
- 端到端 hook：新增→持久化→重载定位、v1→v2 三态迁移、裁决、分别删除
- 节选导出：选区分离/合并、字素边界、跨段落规范化往返、批注截断与坐标
  重映射、上下文不越界、待裁决/失联/旧锚点剔除、节选 id 独立
- 节选打开：合法文件往返、各类非法文件整体拒绝、打开后编辑与重新载入
  完整书稿互不影响


## 节选分享
在阅读页选中文字后点击“加入分享选区”，可跨章节累计多处选区。导出的独立节选只包含被选中的正文及相交的已定位批注：

- 每个（合并后的）选区成为一个片段章节，不连续选区保持分离，不夹带两处之间的未选正文；重叠或首尾相接的选区先合并，正文与批注都不重复。
- 选区端点向外吸附到完整字素边界，两端空白（含段界定符）被裁掉；切片按段界定符拆回段落，重新扁平化/规范化后坐标逐字不变。
- 仅导出与选区相交且坐标证据吻合的已定位批注；待裁决/失联批注及其证据、旧锚点一律不进入分享文件。
- 跨边界批注按各片段可见部分截断，锚点在片段坐标系中重建，两侧上下文以片段可见文字为界（不泄漏选区之外的原文）；单片段批注保留原 id，跨片段副本派生唯一 id。
- 节选书稿使用带 `:excerpt:` 标记的全新 id（并记录 `sourceBookId` 溯源），保存与编辑都独立于原书稿；重新载入完整书稿仍恢复原有批注。

打开分享文件前会整体严格校验（结构、锚点坐标、锚点文字与上下文必须和可见正文完全一致），任何不符都整体拒绝，不写入存储、不改动当前状态。区间采用页面规范化章节文字的 UTF-16 偏移，端点必须处在完整字素边界。
