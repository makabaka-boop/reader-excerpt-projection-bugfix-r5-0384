# 书稿阅读器（React + TypeScript）

导入由「章节 + 段落」组成的本地 JSON 书稿，在规范化文字上做跨文本节点选区批注。
批注锚点是唯一状态源：持久化、画面高亮、导出都取自同一份锚点状态。

## 运行

```bash
npm install
npm run dev       # 开发
npm test          # 57 个单测/集成测试（vitest + jsdom）
npm run build     # 类型检查 + 生产构建
```

## 书稿 JSON 格式

```json
{
  "id": "book-1",
  "title": "书名",
  "version": "1",
  "chapters": [
    {
      "id": "ch1",
      "title": "第一章",
      "paragraphs": ["段落一", { "id": "p2", "text": "段落二" }]
    }
  ]
}
```

内置「示例 v1 / 示例 v2」两个按钮，v2 相对 v1 覆盖：段落拆分、跨节点选区、
重复短句（多处匹配）、文字插入、文字删除（失联）。

## 锚点模型（`src/types.ts`）

每条批注保存一个 `Anchor`：

- `chapterId`：章节身份（不依赖章节序号）
- `start` / `end`：章节扁平文字中的规范化偏移（快速路径）
- `text`：选中文字（跨段时保留 `\n` 段界定符）
- `prefix` / `suffix`：两侧各 32 字上下文（重锚证据）

### 规范化（`src/text/normalize.ts`）

逐段 NFKC + 空白折叠（换行/制表/连续空格归一）。关键点：全角中文标点
（`，。：；！？…` 等）经 NFKC 会被错误映射成 ASCII 标点，因此仅对
「NFKC 结果为纯 ASCII 且不含受保护全角标点」的字素簇应用 NFKC
（兼容连字 `ﬁ`、全角字母/数字等），中文标点原样保留。同时建立正/逆映射，
DOM 原始偏移与规范化偏移可双向换算。

### 扁平文字（`src/text/flatten.ts`）

每章把规范化段落以 `\n` 连接，记录每段 `start/textEnd/end`。选区坐标
全部基于文字偏移，与字号、窗口宽度、换行位置无关——所以改字号/拖窗口后
只需按 Range 重新测量高亮矩形，锚点永不漂移。

## 重锚（`src/text/anchor.ts`）

导入同书新版本（同 `id`、不同 `version`）时，对每条批注：

1. 在章节「去段界」连续文字中查找选中文字；
2. **0 次匹配** → `lost`：保留原锚点与上下文作为证据，不放置任何高亮，绝不猜测；
3. **1 次匹配** → `anchored`：自动迁移（段落拆分天然支持，段界被忽略）；
4. **多次匹配** → `ambiguous`：全部候选按两侧上下文吻合度评分降序，侧栏
   逐条展示「前文【命中】后文」证据，由人工裁决；也可显式标记失联。

同版本重载（刷新页面）走 `ensureAnchored`：坐标与文字均吻合的批注原样保留，
避免把本来唯一的批注误翻成「待裁决」。

## 界面行为

- 拖选（可跨段）后弹出批注框；`Ctrl/⌘+Enter` 保存
- 高亮是覆盖在文字上的矩形层（`Range.getClientRects`），字号/栏宽变化、
  窗口 resize 后自动重算
- 重叠批注：点击命中处循环选中各条，可分别编辑备注、删除
- 侧栏分组：待裁决 / 失联 / 已定位；失联批注展示原文与两侧上下文证据
- 导出 JSON（含全部状态与锚点证据），localStorage 按书 id 持久化

## 节选分享
在阅读页选中文字后点击“加入分享选区”，可跨章节累计多处选区。导出实现见
`src/excerpt.ts` 的 `buildExcerpt`，保证：

- **只含选中正文**：同章选区先按起点排序，重叠或端点相邻的合并；彼此分离的
  选区切成相互独立的片段段落（每段直接取源段落的规范化子串），两处选区之间
  的未选正文（含跨段空隙）绝不进入文件；未选章节整体不出现。
- **端点安全**：区间夹取到章节范围、离开段界定符 `\n`、并向内吸附到最近的
  完整字素簇边界（不切断代理对/组合字符序列）；会被二次规范化裁掉的段首/段尾
  折叠空格同步收紧，因此节选文字重新扁平化逐字不变，高亮不会错位。
- **只含相交的已定位批注**：仅导出 `anchored` 且当前坐标与正文仍吻合
  （`anchorStillValid`）、并与选区有实际文字交集的批注；待裁决、失联、旧锚点、
  他章或不相交的批注一律排除，候选与上下文证据不会泄漏。
- **跨边界批注一致**：批注按节选可见文字裁剪到相交子串，用节选坐标经
  `createAnchor` 重建锚点——位置、id 身份、`text/prefix/suffix` 全部与节选
  可见文字一致（上下文只可能来自已分享文字）；同一批注跨越多个片段只导出一次。
- **非法文件拒绝**：`validateExcerpt` 严格校验格式版本、书稿结构、批注 id
  唯一、状态/字段、坐标界内且端点不在段界上，并要求锚点 text/prefix/suffix
  与按节选坐标重建的结果完全一致。任何不符都抛 `ExcerptError`，调用方在全部
  校验通过后才落库与切换状态，不产生部分更新。
- **与原书稿隔离**：节选书稿使用由「来源 id/版本 + 规范化选区」派生的独立 id，
  存放在 `reader-excerpt:` 存储前缀下，与原书稿的 `reader:` 键空间互不相通。
  校对员在节选中的新增/改注/删除只影响节选；重新导入完整书稿读不到节选批注，
  原书稿的正文与批注保持不变。
